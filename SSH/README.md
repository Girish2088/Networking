# SSH (Secure Shell)

## Purpose

Securely connect to and manage a remote computer.

---

## Why SSH?

SSH encrypts all communication between the client and server.

It protects:

- Username
- Password
- Commands
- Data

---

## Default Port

22

---

## Common Uses

- Remote Login
- Remote Administration
- Execute Commands
- SCP
- SFTP

---

## SSH vs Telnet

SSH
- Encrypted
- Secure
- Port 22

Telnet
- Plaintext
- Insecure
- Port 23

---

## Authentication

- Password Authentication
- Public Key Authentication
