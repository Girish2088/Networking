# SFTP (SSH File Transfer Protocol)

## Purpose

Securely browse and transfer files using SSH.

---

## Default Port

22 (SSH)

---

## Features

- Secure
- Encrypted
- Browse folders
- Upload files
- Download files
- Rename files
- Delete files

---

## SFTP vs SCP

SCP
- Copy files only

SFTP
- Interactive file management

---

## Memory Hook

SFTP = File Manager over SSH
