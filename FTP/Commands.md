# FTP Commands

## Connect

```bash
ftp <IP>
```

Example

```bash
ftp 192.168.1.100
```

---

## Login

```text
USER username
PASS password
```

---

## Show Current Directory

```text
pwd
```

---

## List Files

```text
ls
```

or

```text
dir
```

---

## Change Directory

```text
cd foldername
```

---

## Download File

```text
get filename
```

Example

```text
get notes.txt
```

---

## Upload File

```text
put filename
```

Example

```text
put report.pdf
```

---

## Rename File

```text
rename old.txt new.txt
```

---

## Delete File

```text
delete filename
```

---

## Create Directory

```text
mkdir folder
```

---

## Remove Directory

```text
rmdir folder
```

---

## Exit FTP

```text
bye
```

or

```text
quit
```

---
